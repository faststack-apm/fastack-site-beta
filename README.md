## Working with blog topics

we have two blogs, a public facing marketing focused on, and a second private more technical focused effort. 

blog entries are entered in a specialized markdown format. 

in both cases, new articles are defined in an ai drive fashion. the special syntax supports a DSL approach towards defining article content, inclusive of some syntactical sugar, as detailed below.



Including images

```
	[a sample image||optinal description||/a-sample-image.png]
```

Including videos

```
	[a sample video||/||optinal description||a-screen-recording.mp4]
```

Including code examples

```
[code: optional title for code]
	content would be here
[/code]
	
```
